# T-M1-13 Never-blockable apps and premium limits
Milestone: M1 · Depends on: T-M1-01 · FRD: main rule 9, FR-03, FR-13

## Goal
Enforce the list of apps that can never be blocked, and the free-plan limits
on schedules and websites.

## In scope / out of scope
In: never-blockable list (phone, SMS, emergency, launcher, this app),
free plan limit of 2 schedules, free plan limit of 3 websites, premium
check interface. Out: payment verification (M6), UI for upsell (M3).

## Files likely touched
lib/policy/never_blockable.dart, lib/policy/plan_limits.dart (+ tests)

## Acceptance checks
- [ ] Phone dialer package is rejected when adding to blocklist
- [ ] SMS app package is rejected
- [ ] Emergency dialer is rejected
- [ ] Default launcher is rejected
- [ ] This app's own package (app.blocker) is rejected
- [ ] Free user adding a 3rd schedule is rejected with upgrade prompt
- [ ] Free user adding a 4th website is rejected with upgrade prompt
- [ ] Premium user can add unlimited schedules and websites

No
