# T-M1-05 TOTP code validation
Milestone: M1 · Depends on: — · FRD: FR-08, main rule 4

## Goal
Validate a 6-digit TOTP code against a shared secret, compatible with
Google Authenticator.

## In scope / out of scope
In: TOTP generation, validation with ±1 time step tolerance, RFC 6238 test
vectors. Out: QR code generation (M4), partner setup flow (M4).

## Files likely touched
lib/policy/totp.dart (+ tests)

## Acceptance checks
- [ ] Generated codes match RFC 6238 test values for SHA-1
- [ ] A code from the current 30-second window is valid
- [ ] A code from the previous 30-second window is valid (tolerance)
- [ ] A code from 2 windows ago is invalid
- [ ] Wrong format (not 6 digits) is rejected

No
