# T-M1-01 Change direction classifier
Milestone: M1 · Depends on: — · FRD: main rules 1, 2

## Goal
Given any settings change, classify it as stricter or weaker.

## In scope / out of scope
In: adding/removing apps, adding/removing websites, adding/removing/changing schedules,
raising/lowering limits, toggling strict mode. Out: approval flow (T-M1-02).

## Files likely touched
lib/policy/change_direction.dart (+ tests)

## Acceptance checks
- [ ] Adding an app to the blocklist is stricter
- [ ] Removing an app from the blocklist is weaker
- [ ] Adding a schedule is stricter
- [ ] Deleting a schedule is weaker
- [ ] Lowering a daily limit is stricter
- [ ] Raising a daily limit is weaker
- [ ] Turning strict mode on is stricter
- [ ] Turning strict mode off is weaker
- [ ] Adding a website is stricter
- [ ] Removing a website is weaker

## Device test needed
No
