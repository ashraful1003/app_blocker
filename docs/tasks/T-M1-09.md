# T-M1-09 Rules snapshot format and serialization
Milestone: M1 · Depends on: T-M1-03, T-M1-04 · FRD: ADR-0002

## Goal
Define the rules snapshot JSON format that Dart builds and Kotlin reads.

## In scope / out of scope
In: snapshot data class (Dart freezed model), JSON serialization, all fields
needed by the Kotlin rules engine (blocked apps, websites, schedules, limits).
Out: encryption (M2), Pigeon transport (M2).

## Files likely touched
lib/policy/rules_snapshot.dart (+ tests), test_vectors/snapshot/*.json

## Acceptance checks
- [ ] Snapshot includes blocked app packages, blocked website domains, schedules and limits
- [ ] Dart serializes to JSON and deserializes back to an equal object
- [ ] Snapshot JSON matches the format the Kotlin rules engine expects
- [ ] Empty blocklist produces a valid snapshot with no blocked items
- [ ] Test vector JSON files are valid and used by both Dart and Kotlin tests

## Device test needed
No
