# T-M1-11 Kotlin rules engine: daily limits and website matching
Milestone: M1 · Depends on: T-M1-10 · FRD: FR-04, FR-13

## Goal
The Kotlin rules engine handles daily limits and website domain matching.

## In scope / out of scope
In: limit evaluation (time used vs allowed), website domain matching
(exact and subdomain), combining schedules and limits (blocked if either
says so). Out: browser URL reading (M2), actual usage tracking service (M2).

## Files likely touched
android/rules-engine/src/main/kotlin/.../LimitEvaluator.kt,
android/rules-engine/src/main/kotlin/.../WebsiteMatcher.kt (+ tests)

## Acceptance checks
- [ ] App with 30-min limit and 30 min used: blocked
- [ ] App with 30-min limit and 20 min used: not blocked
- [ ] instagram.com matches m.instagram.com and www.instagram.com
- [ ] instagram.com does not match notinstagram.com
- [ ] An app blocked by limit but not schedule: still blocked
- [ ] An app blocked by schedule but under limit: still blocked
