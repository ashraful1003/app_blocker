# T-M1-12 Shared test vectors for snapshot contract
Milestone: M1 · Depends on: T-M1-09, T-M1-10 · FRD: ADR-0002

## Goal
A set of JSON test cases that both the Dart and Kotlin test suites run,
proving the snapshot contract is consistent.

## In scope / out of scope
In: JSON files in test_vectors/ with input snapshots and expected blocking
results, Dart test that reads and asserts them, Kotlin test that reads and
asserts them. Out: encryption of the snapshot (M2).

## Files likely touched
test_vectors/snapshot/*.json, test/policy/snapshot_contract_test.dart,
android/rules-engine/src/test/kotlin/.../SnapshotContractTest.kt

## Acceptance checks
- [ ] At least 5 test vector cases covering schedules, limits and websites
- [ ] Dart test suite reads test_vectors/ and all cases pass
- [ ] Kotlin test suite reads the same test_vectors/ and all cases pass
- [ ] Adding a new JSON case automatically runs in both suites

## Device test needed
No
