# T-M1-08 Streak counting and reset
Milestone: M1 · Depends on: T-M1-01, T-M1-02 · FRD: FR-10, main rule 8

## Goal
Count clean days (no weaker changes approved) and reset when protection
is weakened or lost.

## In scope / out of scope
In: streak counter, reset on approved weaker change in strict mode, reset on
protection loss (accessibility off, device admin off), milestone markers.
Out: UI display (M3), stats storage (M5).

## Files likely touched
lib/policy/streak.dart (+ tests)

## Acceptance checks
- [ ] Streak starts at 0 when strict mode is first turned on
- [ ] Each full day with no weaker changes increments the streak
- [ ] Approving a weaker change in strict mode resets streak to 0
- [ ] Detection of accessibility being turned off resets the streak
- [ ] Cancelling a 24-hour wait does not reset the streak
- [ ] Milestones at 1, 3, 7, 14, 30, 60, 90 and 365 days are flagged

No
