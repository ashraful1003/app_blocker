# T-M1-04 Daily limit tracking
Milestone: M1 · Depends on: T-M1-01 · FRD: FR-04, main rule 7

## Goal
Track how long an app has been used today and decide when the limit is reached.

## In scope / out of scope
In: setting a limit (5 min – 8 hours), accumulating usage time, blocking when
limit reached, reset at midnight, 5-minute warning. Out: UI (M3), limits and
schedules interaction (handled by the engine combining both).

## Files likely touched
lib/policy/daily_limit.dart (+ tests), android/rules-engine/src/main/kotlin/.../LimitEvaluator.kt (+ tests)

## Acceptance checks
- [ ] 30-minute limit: after 30 minutes of use, isBlocked returns true
- [ ] Time resets at midnight local time
- [ ] Partially used time carries across app restarts within the same day
- [ ] 5-minute warning fires when 25 of 30 minutes are used
