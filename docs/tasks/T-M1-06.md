# T-M1-06 Code lockout after 5 wrong attempts
Milestone: M1 · Depends on: T-M1-05 · FRD: FR-08, main rule 4

## Goal
After 5 consecutive wrong TOTP codes, lock out code entry for 15 minutes.

## In scope / out of scope
In: wrong-code counter, 15-minute lockout timer, reset on correct code.
Out: UI lockout display (M4).

## Files likely touched
lib/policy/code_lockout.dart (+ tests)

## Acceptance checks
- [ ] After 4 wrong codes, the 5th attempt triggers lockout
- [ ] During lockout, code entry is rejected even with a correct code
- [ ] After 15 minutes, entry is accepted again
- [ ] A correct code before 5 wrong ones resets the counter
- [ ] Lockout timer uses monotonic time (not wall clock)

No
