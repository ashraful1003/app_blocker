# T-M1-07 24-hour wait logic
Milestone: M1 · Depends on: T-M1-01 · FRD: FR-09, main rules 3, 5, 7

## Goal
Implement the 24-hour wait as an alternative to a partner code.

## In scope / out of scope
In: start wait, cancel wait, countdown, confirmation after completion,
24-hour expiry if not confirmed, only one wait at a time. Out: UI (M4),
notifications (M3).

## Files likely touched
lib/policy/wait_24h.dart (+ tests)

## Acceptance checks
- [ ] Starting a wait records the change and the start time (monotonic)
- [ ] Only one wait at a time; starting another replaces the first
- [ ] Cancelling a wait does not reset the streak
- [ ] After 24 hours (monotonic), the wait is complete
- [ ] The user must confirm within 24 hours of completion, or it expires
- [ ] Wall clock changes do not affect the countdown
